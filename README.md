## 📋 แท็บแดชบอร์ด

### ดูรายการทั้งหมด
- เลือกหัวข้อจาก dropdown เพื่อกรองรายการ
- กดปุ่ม **ทั้งหมด / ยังไม่จ่าย / รอตรวจ / อนุมัติ** เพื่อกรองสถานะ
- ค้นหาชื่อนักเรียนได้ในช่องค้นหา

### อนุมัติ/ปฏิเสธสลิป
**วิธีที่ 1 — กดจากการ์ดโดยตรง**
- กด **✅ อนุมัติ** หรือ **❌ ปฏิเสธ** ใต้การ์ดที่มีสถานะ "รอตรวจ"

**วิธีที่ 2 — ดูรูปสลิปก่อน**
- กดรูปสลิป (thumbnail) เพื่อเปิดดูเต็มจอ
- กด **✅ อนุมัติ** หรือ **❌ ปฏิเสธ** ในหน้าต่างที่เปิดขึ้น

### ทวงเงิน
กดปุ่ม **📢 ทวงเงิน** (ปุ่มส้ม)
1. เลือกหัวข้อที่ต้องการทวง
2. ใส่ข้อความเพิ่มเติม (ไม่บังคับ)
3. กด **ส่งทวงเงิน** — ระบบจะส่งแจ้งเตือนถึงเฉพาะคนที่**ยังไม่จ่าย**เท่านั้น

> ⚠️ นักเรียนที่ยังไม่เคยแชทกับบอทจะไม่ได้รับข้อความทวง

### ดาวน์โหลด CSV
กดปุ่ม **📥 ดาวน์โหลด CSV** เพื่อ export ข้อมูลทั้งหมดเป็น Excel

## 👥 แท็บลงทะเบียน

ดูว่านักเรียนคนไหนเคยแชทกับบอทแล้วบ้าง (ลงทะเบียนแล้ว = เคยเลือกชื่อตัวเองในบอท)

- **✅ ลงทะเบียนแล้ว** — มี LINE ในระบบ รับแจ้งเตือนและทวงเงินได้
- **❌ ยังไม่ลง** — ยังไม่เคยใช้บอท ต้องให้นักเรียนแชทกับบอทก่อน

## ⚙️ แท็บจัดการ

### เพิ่มหัวข้อการชำระเงิน
1. กรอก **หัวข้อ** (บังคับ)
2. กรอก **จำนวนเงิน** (ไม่บังคับ)
3. เลือก **วันและเวลาครบกำหนด** (ไม่บังคับ)
4. กรอก **รายละเอียด** (ไม่บังคับ)
5. กด **+ เพิ่มหัวข้อ**

> 📢 ระบบจะส่งแจ้งเตือนถึงนักเรียนที่ลงทะเบียนแล้วทุกคนทันที

### เพิ่มนักเรียน
1. กรอก **ชื่อ-นามสกุล** (บังคับ)
2. กรอก **ชื่อเล่น** — จะแสดงในปุ่มเลือกชื่อใน LINE (ไม่บังคับ)
3. กด **+ เพิ่มนักเรียน**

### ลบรายชื่อ / หัวข้อ
กดปุ่ม **ลบ** สีแดงข้างรายการ → ยืนยัน → ลบพร้อมข้อมูลที่เกี่ยวข้องทั้งหมด

> ⚠️ การลบหัวข้อจะลบข้อมูลสลิปและการชำระเงินในหัวข้อนั้นด้วย ไม่สามารถกู้คืนได้

## 🔔 การแจ้งเตือนอัตโนมัติ

| เหตุการณ์ | ระบบทำอะไร |
|-----------|-----------|
| แอดมินเพิ่มหัวข้อใหม่ | ส่งแจ้งเตือนหานักเรียนที่ลงทะเบียนแล้วทุกคน |
| นักเรียนส่งสลิปหลังครบกำหนด | แสดง ⚠️ ล่าช้า ในแดชบอร์ด |
| แอดมินกดทวงเงิน | ส่งแจ้งเตือนหาเฉพาะคนที่ยังไม่จ่าย |

## 🛠️ การตั้งค่าระบบ (Render)

หากต้องการแก้ไข Environment Variables ไปที่  
**Render Dashboard → service → Environment**

| ตัวแปร | ความหมาย |
|--------|----------|
| `LINE_CHANNEL_ACCESS_TOKEN` | Token ของ LINE Bot |
| `LINE_CHANNEL_SECRET` | Secret ของ LINE Bot |
| `SUPABASE_URL` | URL ของ Supabase project |
| `SUPABASE_SERVICE_KEY` | Service role key ของ Supabase |
| `ADMIN_SECRET_KEY` | รหัสสำหรับล็อกอินแดชบอร์ด |

## 🗄️ ดูข้อมูลโดยตรงใน Supabase

ไปที่ [supabase.com](https://supabase.com) → project → **Table Editor**

| ตาราง | เก็บข้อมูล |
|-------|-----------|
| `students` | รายชื่อนักเรียน + LINE user ID |
| `payment_topics` | หัวข้อการชำระเงิน |
| `payments` | บันทึกการจ่ายเงินและสลิป |
| `line_sessions` | สถานะ session ของบอท |

## ❓ ปัญหาที่พบบ่อย

**บอทไม่ตอบหลัง Deploy**  
→ Render Free Tier จะ sleep หลังไม่มีการใช้งาน 15 นาที  
→ แก้โดยเปิด URL แดชบอร์ดก่อน รอให้ตื่น (~30 วินาที)

**ส่งทวงแล้วไม่มีใครได้รับ**  
→ ตรวจว่านักเรียนลงทะเบียนแล้วในแท็บ **👥 ลงทะเบียน**  
→ นักเรียนต้องเคยแชทกับบอทก่อนอย่างน้อย 1 ครั้ง

**ลบหัวข้อไม่ได้**  
→ อาจมี active session ค้างอยู่ → ลองรีเฟรชหน้าแล้วลบใหม่

**Webhook Verify ไม่ผ่าน**  
→ ตรวจว่า Render deploy สำเร็จและ server ทำงานอยู่  
→ เปิด `https://your-app.onrender.com/health` ต้องได้ `{"status":"ok"}`
