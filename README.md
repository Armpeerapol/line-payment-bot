# 📱 คู่มือการใช้งานบอท LINE สภานักเรียน

สำหรับนักเรียนที่ต้องการแจ้งชำระเงิน

---

## 🚀 เริ่มต้นใช้งาน

### 1. เพิ่มบอทเป็นเพื่อน
สแกน QR Code จากแอดมิน หรือค้นหาชื่อบอทใน LINE แล้วกด **เพิ่มเพื่อน**

### 2. เปิดแชทกับบอท
บอทจะทักทายและแสดงเมนูให้อัตโนมัติ

---

## 💳 วิธีแจ้งชำระเงิน

**ขั้นตอนที่ 1** — กดปุ่ม **แจ้งชำระเงิน** ในเมนูด้านล่าง

**ขั้นตอนที่ 2** — เลือกหัวข้อที่ต้องการชำระ เช่น "ค่ากิจกรรม" หรือ "ค่าเดินทาง"

**ขั้นตอนที่ 3 (ครั้งแรก)** — เลือกชื่อของคุณจากรายชื่อ  
> ครั้งต่อไประบบจะจำชื่อให้อัตโนมัติ ไม่ต้องเลือกใหม่

**ขั้นตอนที่ 4** — ระบบจะแสดงข้อมูลการโอนเงิน

```
🏦 ธนาคารออมสิน
เลขบัญชี: 020-478218-462
```

**ขั้นตอนที่ 5** — โอนเงินแล้วถ่ายสลิป → ส่งรูปสลิปในแชทนี้เลย

**ขั้นตอนที่ 6** — รอแอดมินตรวจสอบ ระบบจะแจ้งผลให้ทราบ

---

## 📊 ดูสถานะการชำระเงิน

กดปุ่ม **ตรวจสอบสถานะ** ในเมนูด้านล่าง จะแสดงสถานะทุกหัวข้อของคุณ

| สถานะ | ความหมาย |
|-------|----------|
| ⏳ รอตรวจสอบ | ส่งสลิปแล้ว รอแอดมินตรวจ |
| ✅ อนุมัติแล้ว | ชำระเงินสำเร็จ |
| ❌ ถูกปฏิเสธ | สลิปมีปัญหา กรุณาส่งใหม่ |
| — ยังไม่จ่าย | ยังไม่ได้ส่งสลิป |

---

## ✏️ เปลี่ยนชื่อของฉัน

หากเลือกชื่อผิด กดปุ่ม **"✏️ เปลี่ยนชื่อของฉัน"** ที่แสดงใต้หน้าจ่ายเงิน แล้วเลือกชื่อใหม่ได้เลย

---

## ❓ คำถามที่พบบ่อย

**Q: ส่งสลิปแล้วแต่ไม่ขึ้นสถานะ**  
A: รอสักครู่แล้วตรวจสอบใหม่ หรือติดต่อแอดมิน

**Q: หัวข้อที่เพิ่งจ่ายไม่แสดงให้เลือก**  
A: ปกติค่ะ หัวข้อที่จ่ายแล้วจะซ่อนอัตโนมัติ

**Q: รับแจ้งเตือนไม่ได้**  
A: ต้องเคยแชทกับบอทก่อนอย่างน้อย 1 ครั้ง และไม่บล็อกบอทไว้

**Q: บอทไม่ตอบ**  
A: ลองพิมพ์ "เมนู" หรือกดปุ่มในแถบเมนูด้านล่างค่ะ
